- [canvas-013-crisp-rendering-constant-size-project-titles](done/canvas-013-crisp-rendering-constant-size-project-titles.md) — `feature` — Three invariants for canvas rendering, captured as an **extension to ADR-003** (scope `global`, unchanged): (1) **Crispness invariant** — `app.init({ resolution: window.devicePixelRatio, autoDensity: true, … })` at the single boot site (Canvas.svelte L533); every `Text` and `Graphics` rasterises at the framebuffer's real resolution rather than the previous default-1× upscale. (2) **Constant-screen-size project titles (Miro-style)** — project frame titles render as **HTML overlays** in the existing ADR-003 overlay container, at a constant CSS pixel size (`var(--guppi-size-title)`) at every camera zoom; end-truncates via CSS `text-overflow: ellipsis` against the current frame header width (`bcLayout.width * camera.zoom`), no per-frame JS measurement; z-index 5 (above canvas, below interactive overlays at 10/11/20); `pointer-events: none` so it never swallows pan/drag/right-click/wheel-zoom; subscribes to camera + projects + theme via Svelte 5 runes. The Pixi `Text` allocation that previously held the project title is removed from `drawProjectFrame`, shedding one per-render rasterisation. (3) **Screen-space stroke widths for the borders category** — frame border, BC bubble border, header divider, focus ring (project frame + BC), and all four intra-project edge variants (incl. arrowheads `headLen`/`headW` + ACL notch size) drop the `* z` multiplier; widths are constant CSS pixels (autoDensity handles device-px). Caveats baked in: focus-ring **inset** stays world-space; arrowhead `pullBack` stays world-space because the bubble is drawn at `bcInsideWidth * z` in screen space. BC bubble title + task-count pill + frame header counts label stay in Pixi `Text` and scale with the camera, gaining crispness from the DPR fix (BC text floor + BitmapText-deferred stances both formally documented in the ADR). canvas/README.md gains two new vocabulary entries (Project-title overlay, Crispness invariant) and annotates Missing tile with the title-overlay opacity link. ADR-003 extension dated `## Extension 2026-05-19`. `pnpm check` 0/0/0 (940); `cargo test --lib` 122/122. Verifier: PASS iter 1. Commit `3315a10`. (2026-05-19)
